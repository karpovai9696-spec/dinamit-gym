# Динамит — вариант дизайна v4 (серый + синий, цвета зала)

Одностраничный адаптивный макет сайта тренажёрного зала «Динамит» (Казань).
Собран по правкам владельца из `kimi-design-prompt-dinamit-v2.txt` — как замена
отклонённому варианту «чёрный + ярко-красный» (`dinamit-design/*.pptx`).
Палитра v4 — по фото самого зала (серый металлик тренажёров + синяя обивка),
присланному заказчиком 2026-10-18. Ранее был вариант v3 «графит + медь».

## Открыть
`index.html` — один самодостаточный файл (CSS и JS внутри), фото в `assets/`.
Работает с диска и с любого статического хостинга. Брейкпоинты: мобильная
версия до 900px, приоритетная ширина 360px.

## Что учтено из ТЗ заказчика (v2)
- Тренажёрный зал — база: hero «Тренажёрный зал "Динамит"», блок зала первым,
  программы единоборств — вторым планом ниже.
- Палитра: фон #232529, поверхности #37393F / #43454C, без чистого чёрного;
  ярко-красный не используется; акцент — синий обивки тренажёров #1646B4
  (кнопка, фокус, номера, мелкие метки), белый текст на кнопке — контраст 8:1.
- Запись — анкета: имя + телефон + направление (зал / групповая / дети),
  подпись «Перезвоним в течение 30 минут». Мессенджеры — только в контактах.
- Фото — только реальные фото клуба из `club-photos` (photo-6, 8, 9, 11,
  photo-1 для контактов не понадобился — карта-заглушка). Бассейн и сауна
  (photo-4, photo-7) НЕ использованы — по ТЗ их нужно уточнить у владельца.
- Структура: hero → зал → программы → тренеры → расписание → цены
  (средний «Популярный») → почему мы → анкета → контакты → футер.
- Сохранено: тёмная тема, крупная кириллическая типографика (Bebas Neue +
  Manrope, как в прошлой версии), много воздуха, мобильная версия 360px,
  блок «Состояния кнопок и полей — для разработки» в конце.

## Демо-состояния
Анкета валидируется (имя, телефон), показывает error и состояние успеха.
Блок состояний в конце страницы показывает default/hover/focus/disabled.

## Что заменить перед показом заказчику
- Плейсхолдеры тренеров: реальные имена, регалии и фото (в ТЗ — уточнить).
- Карточки «фото направления» (бокс, кикбоксинг, ММА): реальные фото групп.
- Заглушка карты — встроить Яндекс.Карты (адрес: Казань, просп. Ямашева, 71А).
- Форма сейчас демонстрационная (JS в файле) — подключить отправку на бэкенд
  или в CRM.
